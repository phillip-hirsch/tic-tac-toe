# Tic-tac-toe

Two Players take turns on one device. Built with React, Tailwind CSS v4 and [Vite+](https://viteplus.dev/).

- `vp install` installs dependencies.
- `vp dev` starts the dev server.
- `vp check` formats, lints and type checks; `vp test` runs the tests.

Domain terms are defined in [GLOSSARY.md](GLOSSARY.md).
